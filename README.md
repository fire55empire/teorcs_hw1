# FSMachine

Программа для работы с конечными автоматами (ДКА/НКА).
> *Примечание*: пути всех файлов пишутся относительно корня проекта, все входные данные считаются корректными.

---

## Сборка и запуск

Сборка выполняется через *make*

После сборки появится исполняемый файл FSMachine.exe

## Режимы работы
### 1. Запуск автомата на строке

> ./FSMachine run filepath input

filepath — путь к файлу с описанием автомата

input — строка входных символов, перечисленных через пробел (например "0 1 0 1")

Программа проверит, принимает ли автомат строку - появится сообщение об этом (true/false)

### 2. Преобразование NFA в DFA

> ./FSMachine refactor filepath1 filepath2

filepath1 — исходный автомат DFA/NFA

filepath2 — файл, куда будет записан полученный DFA

## Работа программы

### Формат входного файла
Файл с описанием автомата имеет формат:

> n               # число состояний
> 
> m               # размер алфавита
> 
> starts          # список стартовых состояний (числа через пробел)
> 
> accepts         # список принимающих состояний (числа через пробел)
> 
> src sym dst     # переходы, одна строка = один переход
> 
> ....

### Почему команда run работает и для NFA, и для DFA?
Внутреннее хранилище переходов у автомата универсальное:

> std::vector<std::vector<std::vector<int>>> transitions

где transitions[state][symbol] — список возможных следующих состояний.

Для DFA список всегда содержит не более одного состояния, для NFA список может содержать несколько состояний, 
поэтому функция accepts одинаково корректно обрабатывает как DFA, так и NFA:

В случае DFA автомат движется по единственному пути, в случае NFA поддерживается множество возможных состояний, которое обновляется на каждом шаге.

### Преобразование из NFA в DFA
> Метод преобразования основан на построении подмножеств.

Каждое состояние нового автомата соответствует множеству состояний исходного NFA.

Начальное состояние DFA — это множество всех стартовых состояний NFA.

Принимающими в DFA становятся те множества, которые содержат хотя бы одно принимающее состояние NFA.

Для каждого символа входного алфавита из текущего множества берутся все возможные переходы и объединяются в новое множество.

Процесс повторяется, пока не будут рассмотрены все достижимые множества.
