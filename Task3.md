# Task 3: Преобразование регулярных выражений в конечные автоматы

## Описание

Реализован метод `FinStateMachine::from_regex()`, который преобразует регулярное выражение в конечный NFA по алгоритму Томпсона.

## Поддерживаемые операции

- **Цифры**: `0-9` - символы алфавита
- **Конкатенация**: `αβ` (неявная)
- **Альтернатива**: `α|β`
- **Клини**: `α*` (0 и более повторений)
- **Плюсик**: `α+` (1 и более повторений)
- **Вопросик**: `α?` (0 или 1 повторение)
- **Скобки**: `(α)` для группировки

## Использование

Команда для преобразования регулярного выражения в автомат:

```bash
./FSMachine regex <regex> <output_file>
```

## Примеры тестов

### Тест 1: Базовый пример - один или более нулей, затем один или более единиц

```bash
./FSMachine regex "0+1+" test_output1.txt
```

Создаст автомат, принимающий строки вида: `0...01...1` (хотя бы один ноль, затем хотя бы одна единица).

Проверка работы автомата:
```bash
# Должно вернуть true
./FSMachine run test_output1.txt "0 1"
./FSMachine run test_output1.txt "0 0 1 1"

# Должно вернуть false
./FSMachine run test_output1.txt "1 0"
./FSMachine run test_output1.txt "0"
```

### Тест 2: Альтернатива и опциональный символ

```bash
./FSMachine regex "(0|1)2?" test_output2.txt
```

Создаст автомат, принимающий: `0` или `1`, затем опционально `2`.

Проверка:
```bash
# Должно вернуть true
./FSMachine run test_output2.txt "0"
./FSMachine run test_output2.txt "0 2"
./FSMachine run test_output2.txt "1"
./FSMachine run test_output2.txt "1 2"

# Должно вернуть false
./FSMachine run test_output2.txt "2 2"
./FSMachine run test_output2.txt "0 0"
```

### Тест 3: Клини звездочка

```bash
./FSMachine regex "0*" test_output3.txt
```

Создаст автомат, принимающий любое количество нулей (включая 0 раз).

Проверка:
```bash
# Должно вернуть true (для пустой строки нужно специальное тестирование)
./FSMachine run test_output3.txt "0"
./FSMachine run test_output3.txt "0 0 0"
```

### Тест 4: Универсальный автомат

```bash
./FSMachine regex "(0|1)*" test_output4.txt
```

Создаст автомат, принимающий любые последовательности из нулей и единиц.

Проверка:
```bash
# Должно вернуть true
./FSMachine run test_output4.txt "0 1 0 1"
./FSMachine run test_output4.txt "0 0 0"
./FSMachine run test_output4.txt "1 1 1"
```

### Тест 5: Комплексное выражение

```bash
./FSMachine regex "(0|1)+2*" test_output5.txt
```

Принимает один или более символов из `{0,1}`, затем любое количество двоек.

## Тестирование валидации

### Проверка ошибок

```bash
# Непарные скобки - должно выдать ошибку
./FSMachine regex "((0)" test_err.txt

# Недопустимые символы - должно выдать ошибку
./FSMachine regex "a" test_err.txt

# Пустое выражение - создаст автомат для пустой строки
./FSMachine regex "" test_empty.txt
```

## Полный цикл тестирования

1. Создать автомат из регулярного выражения:
   ```bash
   ./FSMachine regex "0+1+" test.dfa
   ```

2. Преобразовать в детерминированный автомат:
   ```bash
   ./FSMachine refactor test.dfa test_dfa.dfa
   ```

3. Минимизировать автомат:
   ```bash
   ./FSMachine minimize test_dfa.dfa test_min.dfa
   ```

4. Проверить эквивалентность с другим автоматом:
   ```bash
   ./FSMachine equal test.dfa test_min.dfa
   ```

5. Проверить, является ли язык универсальным:
   ```bash
   ./FSMachine universal test_min.dfa
   ```

## ВАЖНО

- Все входные строки для команды `run` должны быть разделены пробелами
- Пустая строка не может быть передана как аргумент команды `run`
- Регулярные выражения чувствительны к пробелам (они игнорируются парсером)
- Приоритет операций: скобки -> унарные операторы (*, +, ?) -> конкатенация -> альтернатива (|)
